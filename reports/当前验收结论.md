# 当前验收结论

截至 2026-11-05，512 个动态任务的 1024 次真实模型运行已完成并通过独立审计。原描述中的 35% 降幅未复现。

| 要求 | 当前证据 | 结论 |
|---|---|---|
| 模块化真实 Agent/MCP 评估 | 模型决策、MCP stdio、Docker 服务、用例矩阵、状态验证和证据导出 | 原型已实现；业务复杂度仍有限 |
| Docker 和系统调用限制 | 固定镜像；实际 fork 子进程中八个禁止 syscall 均为 EPERM，允许 getpid 正常 | 固定规则有效；任意操作的语义授权未实现 |
| 越权与工具误用 | 资源及参数策略；强制越权回归与真实状态快照 | 已实现限定资源模型；不能推广至任意工具 |
| 自动红队 | 描述、返回、假错误、中文注入，畸形协议，超时与确认丢失 | 固定模板已实现；自适应攻击未实现 |
| 性能与压力 | 相同 SQLite 读取，1/4/8 并发，3987 次正确；71.29/254.55/463.81 请求每秒 | 短时本地工具服务负载；尚无耐久或模型容量结论 |
| 标准化轨迹 | v1 schema、运行 ID、顺序、原始 SHA-256 | 1024 次运行的 19,392 条事件已校验 |
| 500+ 动态用例 | 512 个实例、两类工作流、四资源家族、八条件、十六状态 | 基线和防护组各 512 次，覆盖及状态审计通过 |
| 降低 35% | worker 超时 128/512 → 128/512，协议错误 64/512 → 64/512，重复修改 12/512 → 0/512 | 注入的首次故障仍发生，防护降低了本批重复修改 |

任务完成率由 500/512（97.66%）升至 512/512（100%）。模型请求由 1728 降至 1536，减少 11.11%。worker 超时是在固定故障场景中观测到的事件。重试和幂等控制可以恢复任务、避免重复提交，首次超时仍计入超时率。任务偏离按外部状态与读取行为判断。

CLI 额度中断已通过断点续跑补齐，历史错误归档于 `workflow-512-r2/attempts/`。执行期间调整了并发，因此耗时仅作描述。防护组合包含授权、重试、截止时间与幂等控制，单项收益需要消融实验。详见 [全量实验报告](workflow-512-r2/实验报告.md)。

近期项目讨论和具体优先级见 [研究比较](../RESEARCH-20261105.md)。后续方向包括防护消融、不同业务状态机、自适应长时序攻击和 MCP 生命周期攻击。
